# Цифровой профиль сотрудника: запуск на Windows

**Если вам передали автономную поставку для закрытого контура**, откройте в ней `START_HERE_RU.html` двойным щелчком. Инструкция откроется без интернета. Для работы с кадровыми данными используйте именно эту поставку.

**Если вы скачиваете проект с GitHub**, следующие шаги запустят на вашем компьютере демоверсию с 15 вымышленными сотрудниками. Для первой сборки нужен интернет.

1. Установите [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/), запустите его и дождитесь надписи **Engine running**.
2. [Скачайте ZIP с проектом](https://github.com/akezhan96/digital_passport_emp/archive/refs/heads/render-demo.zip). Нажмите правой кнопкой на архив → **Извлечь все**. Откройте распакованную папку.
3. Дважды щёлкните **start-local.cmd**. При первом запуске дождитесь строки **«Готово»**. В этом же окне появятся логин и пароль.
4. Откройте [http://localhost:8080](http://localhost:8080) и войдите с указанными данными.

**После перезагрузки** запустите Docker Desktop и снова откройте `start-local.cmd` из той же папки. Пароль и записи сохранятся: пароль хранится в файле `.env.local`, а записи — в томе Docker `digital_profile_local_demo_database`.
